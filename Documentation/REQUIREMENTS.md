## Material limitations

1. A generic stock router without an authorized API cannot support one-tap access control. No security bypass is implemented. An extensible HTTPS protocol exists, currently with one optional Linux/nftables reference agent; router-specific adapters are not implemented.
2. Discovery does not prove online/offline or Internet access. MAC addresses can be unavailable under iOS permissions. IPv4-only scan range /22–/30; actual subnet chosen from active Ethernet-type local interfaces/default routes, not a fixed gateway or router brand.
3. Router set readback is verified separately from Internet loss/restoration. Alternate uplinks, flow offload, MAC rotation and relaying through a second client may bypass rule effects; unsupported topologies require another adapter.
4. Runtime certification for the supplied device/OS/jailbreak tuple, no-crash behavior and resource use require the physical device.
5. No claim that this beta fulfils the final definition of done; pending items remain explicit.
