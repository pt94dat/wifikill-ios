Access control compatibility

Discovery is independent of router brand. Kill/Unkill currently requires the opt-in LanGuard HTTPS agent on a Linux/nftables gateway you administer. It does not work on every stock router. Rules expire automatically after five minutes.

Router rule readback is reported separately from actual Internet connectivity. End-to-end verification requires a controlled client device. IPv4 scanning is limited to /22–/30; isolated and silent devices may be absent. MAC addresses may be unavailable under iOS permissions.

Removal and recovery

Restore all leases before removal. Use Sileo to uninstall. If the app crashes or the phone disconnects, access leases expire on the gateway independently. Gateway administrators can run nft flush set inet languard blocked to restore all LanGuard-managed access immediately.
